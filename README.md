# Maxfolio

My personal portfolio — career history, project work, ongoing learning, and contact details.

**Live:** [maxfolio-io.vercel.app](https://maxfolio-io.vercel.app)

## Stack

- [Next.js](https://nextjs.org) (App Router)
- React 19
- TypeScript
- Tailwind CSS

## Pages

- `/` — Home
- `/career` — Story and full career timeline
- `/work` — A draggable collage of every project and task shipped
- `/learning` — Long-form writing on production systems
- `/contact` — Get in touch
- `/resume` — Résumé, proxied live from Google Drive
